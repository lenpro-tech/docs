## Получите доступ

Пока магазин в превью, репозиторий каталога закрытый. Оставьте свой
логин GitHub в [форме листа ожидания](/#магазин-открывается-скоро) — вы
получите доступ на чтение, этого хватает, чтобы сделать форк и открыть
pull request.

## Шаги

1. Сделайте форк [каталога игр](https://github.com/lenpro-tech/games) и клонируйте его.
2. Выполните `npm ci` в корне репозитория (Node 22).
3. Создайте игру: `cd games && npx game-kit create <slug> --no-install && cd ..`.
   В `games/<slug>/package.json` выставьте всем зависимостям
   `@table-games-engine/*` ту же точную версию, что в корневом
   `package.json`, и выполните `npm install` в корне. Не коммитьте
   lockfile внутри `games/<slug>/`.
4. Соберите игру с ИИ — см. [Игра с помощью ИИ](/docs/llm/).
5. `npm run check -w games/<slug>` должен проходить; сыграть —
   `npm run preview -w games/<slug>` (нужен Docker).
6. Откройте pull request из форка. Мейнтейнер запускает CI, играет в
   игру и проверяет её по чек-листу.

Каждую игру перед публикацией проверяет и играет человек. Одобренные
игры выходят со следующим релизом каталога.

## Правила

- `slug` совпадает с именем папки; `plugin.id` — со `slug`;
  `plugin.version` — с `version`.
- Любое изменение вне `tests/` требует повысить `version`.
- Опубликованную игру не удаляют и не переименовывают — вместо этого
  ставят `"listed": false`.
- `client.entry` должен лежать внутри `client/dist/`.
