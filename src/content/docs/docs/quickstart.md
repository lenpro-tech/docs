## Что понадобится

- Node.js 22 или новее.
- Docker — только чтобы играть локально (`preview`).
- ИИ-агент для программирования, который умеет запускать команды в терминале (мы проверяем на Claude Code).

## 1. Создайте игру

```sh
npx @table-games-engine/game-kit create my-game
cd my-game
```

Вы получите рабочую дуэль на двоих: логику, тесты, клиент для браузера и
`game.json`. Это заготовка — замените её своей игрой.

## 2. Соберите её с ИИ

Дайте агенту правила игры и укажите на инструкцию, которая лежит в
пакете, — см. [Игра с помощью ИИ](/docs/llm/).

## 3. Сыграйте

```sh
npm run preview
```

Откроет оба места за столом рядом в браузере, а за ними — настоящий
игровой сервер в Docker. Каждый ход идёт через сервер, ровно как в
магазине.

## 4. Проверьте

```sh
npm run check
```

Запускает всё, что запускает CI магазина: проверяет `game.json`, логику
на запрещённые конструкции и типы, гоняет ваши тесты, играет 1000
случайных матчей на каждый пресет и число игроков и собирает клиент.
Готово, когда напечатано `check: OK`.

| Шаг | Что доказывает |
|---|---|
| `npm test` | правила, на которые есть тесты, работают как написано |
| `npm run simulate` | случайные матчи всегда заканчиваются, а каждый предложенный ход принимается |
| `npm run check` | игру можно отправлять на публикацию |
| `npm run preview` | в неё интересно играть, и клиент работает в браузере |
