## Кто что делает

**Вы придумываете и проверяете, ИИ пишет код.** На вас — правила,
решение по каждой неоднозначности и ответ на вопрос «интересно ли
играть». ИИ пишет логику, тесты и клиент и прогоняет проверки, пока они
не пройдут.

## Дайте агенту инструкцию

В каждом пакете игры лежит skill-файл: полный контракт, правила,
которые проверяет `check`, и таблица типичных ошибок:

```
node_modules/@table-games-engine/game-kit/skill/create-store-game.md
```

`AGENTS.md` в заготовке уже ссылается на него. Если агент умеет читать
сайты, вся документация есть одним файлом:
[`https://logigra.ru/llms-full.txt`](/llms-full.txt) (на английском —
модели лучше следуют английским инструкциям).

## Стартовый запрос

```text
Build the game described in rules.md as a store game.
Follow node_modules/@table-games-engine/game-kit/skill/create-store-game.md.
Locales: ru, en. Players: 2. Presets: "small" (5x5) and "classic" (8x8).
Before writing code, list every ambiguity in the rules and propose a
decision for each; wait for my answers and write them into rules.md.
You are done when `npx game-kit check` prints `check: OK`.
```

Писать запрос можно и по-русски — важно, чтобы агент прочитал skill-файл
и спросил вас про неоднозначности в правилах.

## Цикл работы

1. `npx game-kit test` — сценарии матчей и тесты на отдельные правила.
2. `npx game-kit simulate -n 200` — случайные матчи; при ошибке
   печатается seed, по которому матч можно повторить.
3. `npx game-kit check` — полный прогон CI.
4. `npm run preview` — вы играете за обе стороны и решаете, что менять.

Ваша роль в цикле: прочитать, какие решения по правилам записал ИИ,
сыграть и сказать, что не так. Сломанные правила ловят проверки; скучную
игру поймаете только вы.

## Пример: Gridball

Gridball — футбол на бумаге в клетку — собрал ИИ-агент по описанию
правил, без единой правки кода человеком. `check` стал зелёным со второго
запуска, 2000 симулированных матчей прошли без ошибок, игра прошла
плейтест. Сложнее всего агенту дались пенальти; каждое принятое решение
записано в файле правил.
