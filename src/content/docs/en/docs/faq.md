## Which AI can I use?

Any coding agent that can read files and run shell commands. We test
with Claude Code.

## Do I need to know how to program?

Reading TypeScript helps you judge what the AI wrote. The AI writes the
code; you decide the rules and check the result by playing.

## Is it free?

Yes, for authors at launch.

## When does the store open?

Soon. Join the [waitlist](/en/#the-store-opens-soon) to hear first and
to get access for publishing.

## Who owns my game?

You do. You grant Logigra the right to host it and let people play it;
the exact terms come with the store launch.

## Can I use it in a classroom?

Yes — a Russian-language format for high schools is described at
[/schools/](/schools/).
